# GRW ScriptHook 魔改版（Beta1.0）

《幽灵行动：荒野》（Ghost Recon Wildlands）的
ScriptHookV 同类框架。以 `dinput8.dll` 代理形式随游戏加载，暴露
C ABI，并按 ASI 插件约定加载 `plugins\` 下的 `.asi` 插件。

> 本项目为原版 **grw-scripthook** 的中文魔改版，在原版框架之上
> 重做了游戏内菜单、中文本地化，并新增了多项实用功能。

## 这是什么

原版是作者反编译《幽灵行动：荒野》逐步定位得到的引擎扩展框架。  
游戏本身没有脚本层、没有控制台、没有可直接使用的API，因此框架的每一项能力都源于游戏引擎中一段被定位并验证过的函数或字段。

魔改版在保留全部底层能力（载具、实体、相机、事件、原生UI 等）的前提下，重点改进了**F4 模组菜单**。  
改为独立的 D3D11/ImGui 覆盖层渲染（原生支持中文字体），并对接入`scripthook.ini` 的翻译表，实现可高度自定义汉化的模组菜单界面。

## 魔改内容一览

自魔改分支以来的主要变更（按功能归类，详见 Git 提交）：

- **菜单渲染重构**：用 D3D11 + Dear ImGui 覆盖层重绘 F4 菜单，内置 CJK 字体，中文显示不再依赖原生 UI。
- **插件目录与配置约定规范化**：各个插件统一放置到 `plugins\` 目录下对应的插件名目录，每个插件的 `.ini` 配置文件与其 `.asi` 插件文件，同目录同名放置。
- **完整中文本地化**：对接 `scripthook.ini` 翻译表，并可自定义配置第三方插件的菜单翻译。
- **菜单体验改进**：增加自定义配置菜单显示顺序、提示，优化菜单导航与交互。
- **模组功能设置**：添加插件总开关、额外功能开关、各插件独立开关设置。
- **CPU 核心调度（按启动阶段分别设置）**：为游戏启动的三个阶段各设一档 —— **Logo 阶段**（此阶段禁超线程可让 logo 秒进）、**窗口加载阶段**（加载界面/主菜单/大厅：部分机器禁小核可秒进，部分机器如被 Win11 自动优化过则需"全部核心(强制)"）、**游玩阶段**（禁超线程 / 禁 CPU0 缓解间歇性卡顿）。每档可选：不干涉（什么都不设置，含系统自动优化）/ 全部核心(强制) / 禁超线程 / 禁小核（仅 Intel 12代+ 大小核，其它平台不适用且不做改动）/ 及其组合（游玩档另有禁 CPU0 的组合）。另有**每阶段的进程优先级**（启动的两个加载阶段：低 / 低于正常 / 不干涉 / 正常 / 高于正常 / 高；游玩阶段：不干涉 / 正常 / 高于正常 / 高；不提供"实时"，以免拖累系统输入与音频）与"游玩时最大核心数"上限（**只作用于游玩阶段**，启动阶段不做限制，避免影响启动）。除让引擎按当前阶段的核数自居外，还会真实设置游戏进程的亲和性与优先级（任务管理器「设置相关性」可见），并在游戏启动时自己改优先级的情况下保持住所设档位。
- **载具与生成优化**：载具菜单汉化、生成载具时缓存预热，优化首次召唤载具的生成速度，且世界重载后不重复预热。
- **跳过开场视频**：内置自写的skipintro插件，可跳过游戏启动时的 Nvidia/Ubisoft片头视频、存档提示/光敏警告视频。
- **「最后的仪式」闪退修复（LastRites_dlcfix 插件）**：进入该新 DLC 加载中闪退，是游戏自身缺陷——锁区版里 Uplay 对该**免费更新**的授权查询返回「未获得」，游戏随后在加载流程中走了一条解引用空指针的分支（实测固定崩在 `GRW.exe+0xE09DA51`，读 `null+0x340`）。插件在游戏取该授权函数指针的地方（`kernel32!GetProcAddress`）拦下它，**只对实测确认的那一个条目 `3718`** 按「已获得」处理，其余条目（含全部付费 DLC）一律返回游戏原本得到的答案；该条目号**写死在代码里、不可配置**，以免被改指向付费内容。菜单里只有一个开关（**默认关**），关闭时**不安装任何钩子**，游戏行为与未装本插件完全一致；**改动于下次启动游戏时生效**（游戏在启动时读取并缓存授权结果）。**仅限单机使用**（游戏含 EasyAntiCheat）；与社区补丁（Koaloader 代理 + 第三方解锁器）**不要同时启用**；官方修复推送后请关闭开关并删除 `plugins\LastRites_dlcfix`。
- **魅影模式不删档（GhostNoWipe 插件）**：魅影模式中完全死亡（暴毙，或倒地未救起流血致死）后，游戏会提示失败并删除该存档。经文件操作探针 + 替换验证确认，删档由**两处记录**构成：一是把 `N.save` 改名成 `N.save.delete` 并写入一份 `.delete`（**这个 `.delete` 本身就是存档界面读取的"已删除"记录之一**，不是临时残留）；二是在改名之前，**游戏已经把"本局结束"写进了 `N.save` 自己的内容里**（替换验证：放回死亡前的存档文件，档就正常列出；放死亡那一刻写入的那份，档就不列出）。插件因此同时守住两样：**改名一律丢弃且不留下任何替代文件**，对 `.delete` 的写入**改道到 `%TEMP%\GhostNoWipe\`**，并把存档内容**回填**——回填用的是**上一代**副本（`X.save.prev`）：副本两代滚动维护，而"写标记"只发生一次、且比死亡画面早 9 秒，所以上一代必然是玩家还活着时的存档。最终做到**磁盘上不残留任何删档痕迹**。回到存档界面时游戏内存里仍认为该档已删（这一步发生在进程内，无法也不需要拦），**重启游戏重新扫描目录后该档即恢复显示并可继续游玩**（进度退回最近存档点）。菜单里只有一个开关（**默认开**）；关闭时**不安装任何钩子、不写日志**，游戏行为与未装本插件完全一致。**注意**：在界面里手动删除魅影档走的是同一套流程，同样会被拦下 —— 确实要删档时，请先在菜单或 `plugins\GhostNoWipe\GhostNoWipe.ini` 里关闭插件。**仅限单机使用**（游戏含 EasyAntiCheat）；开启云同步时本地保留的存档可能与云端状态冲突，需自行取舍；官方修复推送后请关闭开关并删除 `plugins\GhostNoWipe`。

## 安装

1. 将 `dinput8.dll`、`plugins\`、`scripthook.ini` 放入游戏根目录（与 `GRW.exe` 同级）。
2. 各种插件放入对应的路径 `plugins\<插件名>\<插件名>.asi`（每个插件一个文件夹）。

```
Tom Clancy's Ghost Recon Wildlands/
├── GRW.exe
├── dinput8.dll
├── scripthook.ini     主配置文件
├── logs/              运行日志
└── plugins/           插件目录（每个插件一个子文件夹）
```

---

## 主配置文件（scripthook.ini）说明

```ini
[loader]
load_plugins=1          ; 0 = 启动时不加载任何插件
cpu_boot=0              ; Logo 阶段：        0=不干涉 1=全部核心(强制) 2=禁超线程 3=禁小核 4=禁超线程+小核
cpu_prio_boot=2         ; Logo 阶段优先级：  0=低 1=低于正常 2=不干涉 3=正常 4=高于正常 5=高
cpu_window=0            ; 游戏窗口加载阶段：同上（例：解 logo 卡用 2；解窗口无限加载用 3 或 1）
cpu_prio_window=2       ; 窗口加载优先级：  同上（启动阶段可选"低/低于正常"，加载时让出机器）
cpu_play=0              ; 游玩阶段：        附加 5=仅禁CPU0 6=禁超线程+CPU0 7=禁小核+CPU0 8=三者全禁
cpu_prio_play=2         ; 游玩阶段优先级：  2=不干涉 3=正常 4=高于正常 5=高（不提供低两档）
cpu_cores=0             ; 游玩阶段最大逻辑核心数（0 = 不限制；启动阶段不做限制）

[plugins]
chaos=0                 ; 每个插件一行，1 启用 / 0 禁用

[Settings]
Languages=zh_cn,en      ; 设置菜单中可选的语言列表（逗号分隔）
Language=zh_cn          ; 当前菜单语言
```

### 插件菜单的汉化（翻译表用法示例）

框架菜单中的**每一个标签文本都是“翻译 key”**：显示前会先在当前语言（由 `[Settings] Language` 决定）的翻译表里查找，查不到就回退显示英文原文。  
因此**插件无需任何改动**，只要在 `scripthook.ini` 里补上对应的翻译条目，就能把它的菜单汉化。

**插件也可以把翻译放进自己的配置文件** `plugins\<插件名>\<插件名>.ini`（同样的 `[zh_cn]` / `[zh_cn.<菜单标题>]` 节格式）：查找时**插件自己的 ini 优先**，找不到再回退 `scripthook.ini`。这样单独分享插件时，翻译跟着插件走，不需要动总配置文件。

以 firstperson 插件（菜单标题 `First person`）为例：

**① 根菜单行标题** —— 加在全局表 `[zh_cn]` 下：

```ini
[zh_cn]
First person = 第一人称
```

**② 该插件菜单内部的选项** —— 新建子节 `[zh_cn.First person]`
（配置段名为菜单标题原文），键为菜单项原名，值为翻译后的名字：

```ini
[zh_cn.First person]
Enabled = 第一人称
Hide head = 隐藏头部
Forward cm = 前后调整(cm)
Height cm = 高低调整(cm)
ADS settle ms = 开镜速度(ms)
First-person view: hide head, adjust eye height and distance. = 第一人称视角，可隐藏头部，可调整视角前后高低
```

## 构建

- **Windows（MSVC）**：`pwsh ./build_msvc.ps1`
- **Linux / Proton（MinGW）**：`make`

构建后，输出 `dinput8.dll` 到游戏根目录、输入插件到以下目录 `plugins\<name>\`。
