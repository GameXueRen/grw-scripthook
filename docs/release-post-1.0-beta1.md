## 这是什么

《幽灵行动：荒野》的脚本扩展框架（原版 **grw-scripthook**）的**中文魔改版**。它以 `dinput8.dll` 代理的形式随游戏加载，**不修改游戏本体文件**。

魔改部分重做了游戏内菜单：用独立的覆盖层重新渲染（自带中文字体，中文不再依赖游戏原生 UI），界面文案做成**中英双语、可当场切换**，也能自己改写；另附 **8 个开箱可用的插件**。

## 有什么

**菜单**
- `F4` 呼出，覆盖层渲染，翻页、调值都有快捷键提示；
- 中文 / 英文内置、设置里当场切换，根菜单顺序也能自己排；想改文案或加一门语言，往游戏目录放一份 `lang.ini` 即可（包里带了模板）。

**8 个内置插件**（都随包，进游戏后按需打开）

| 插件 | 做什么 |
| --- | --- |
| 光学迷彩加强 | 蹲下触发特效时，敌人视觉感知大幅下降 |
| 天气 & 时间实时控制 | 实时调整游戏内时间、天气与时间流速 |
| 弹药上限 | 调整所有武器可携带的弹药上限 |
| 自绘聊天框（支持输入中文） | 游戏内聊天框支持中文输入 |
| 第一人称 | 第一人称视角，含视角参数预设与热键切换 |
| 延展视野范围 | 覆盖游戏视野（FOV），可随时还原 |
| 跳过启动时的动画视频 | 跳过启动时的 4 段片头与警示动画 |
| 载具派遣 | 65 种载具的中文目录，点一下召唤到身边 |

> 左列就是菜单里的**页名**，装好后照着找即可。

## 怎么装

1. 下载 `GRW-ScriptHook-1.0-beta1.zip` 并解压；
2. 把解压出来的内容**整体**放进游戏根目录（和 `GRW.exe` 同一个文件夹）；
3. 启动游戏；
4. 进游戏后按 **F4** 打开菜单；
5. 去 `ScriptHook 设置 → 各插件开关`，把想要的插件打开；
6. 再进对应插件的页面，**把它的功能开关打开**。

> ⚠ 第 6 步别跳过：**插件里的功能默认都是关的**，只打开插件本身还看不出效果。

## 第一次进去注意什么

- 8 个插件会全部载入，但**每个插件自己的功能开关默认全是关的** —— 先看不到变化是正常的，去对应页面打开即可；
- 语言在 `ScriptHook 设置 → 菜单语言` 里切（内置中文、英文）；
- 想改某句文案、或自己加一门语言：游戏目录放一份 `lang.ini`（也可以给每个插件目录各放一份），包里的 `lang.example.ini` 就是模板，照着改就行。

## 出问题怎么反馈

把游戏目录下的 **`logs\` 整个文件夹**发出来（框架和每个插件各有一份日志），再补一句「什么时候、做了什么、看到什么」，基本就能定位。
也可以到 GitHub 提 Issue。

## 注意

- 目前是 **beta1**，有问题欢迎反馈；
- 建议**单机**使用；
- **不要**和其它同样用 `dinput8.dll` 代理的 Mod 同时装；
- 在 PvP（幽灵战争 / 雇佣兵）里，插件会被自动禁用 —— 这条**欢迎重点确认**；
- 卸载：删掉 `dinput8.dll`、`scripthook.ini`、`plugins\` 三个即可回到原样。
