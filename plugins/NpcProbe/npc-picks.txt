# third-party plugin, which is where they were first copied from. They are game
# data like any other id, so this file does not rest on that: every row below was

#   kind  the engine's own classification number
#   group the framework's bucket over kind - not engine data
#

# "summon next in the list" - an id this build does not hold answers with
